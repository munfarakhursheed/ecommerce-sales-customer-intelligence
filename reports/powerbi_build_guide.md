# Power BI Build Guide
1. Get Data → Text/CSV → import all CSVs from `data/`.
2. Create relationships listed in README.
3. Create measures:
   - Revenue = CALCULATE(SUM(order_items[gross_revenue]), orders[order_status] = "delivered")
   - Indicative Gross Profit = CALCULATE(SUM(order_items[gross_profit]), orders[order_status] = "delivered")
   - Delivered Orders = CALCULATE(DISTINCTCOUNT(orders[order_id]), orders[order_status] = "delivered")
   - AOV = DIVIDE([Revenue],[Delivered Orders])
   - On-time Delivery % = AVERAGE(orders[delivered_on_time])
4. Build pages: Executive Overview, Product & Profitability, Customer Intelligence, Operations & Delivery.
5. Add date, region, category and payment slicers.
6. Validate totals against SQL queries and Python notebook.
Note: a `.pbix` file is not generated by this package; these are import-ready source files and build instructions.
